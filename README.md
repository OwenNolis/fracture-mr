# Fracture - Mixed Reality Project

This is a Mixed Reality (MR) / Virtual Reality (VR) project built with Unity.

## Process

This project was developed using **Unity 6000.2.7f2**.

## Getting Started

### Prerequisites

* Unity Hub
* Unity Editor 6000.2.7f2 (or compatible version)
* Visual Studio 2022 (or VS Code / JetBrains Rider)

### Installation

1. Clone the repository or download the source code.
2. Open Unity Hub.
3. Click **Add** and select the `fracture-mr` folder (or the parent folder containing `Project Facture`).
    * *Note: Ensure you open the folder containing the `Assets` and `ProjectSettings` directories.*
4. Open the project in Unity. It may take some time to import assets on the first launch.

## Project Structure

* **Assets**: Contains all the source assets for the project.
  * `Scenes`: Project scenes (e.g., Main Menu, Gameplay).
  * `Scripts`: C# scripts for game logic.
  * `Materials`: Materials used for 3D models.
  * `Models`: 3D models and meshes.
  * `Prefabs`: Pre-configured GameObjects.
  * `XR`: XR-specific settings and assets.
* **ProjectSettings**: Configuration files for the Unity project.
* **Packages**: Unity Package Manager dependencies.

## Features

* **XR Interaction**: Built with Unity's XR Interaction Toolkit.
* **VR/MR Ready**: Configured for Virtual and Mixed Reality experiences.
